# Projet-Cisco

Description : Ce projet est une simulation réseau créée avec Cisco Packet Tracer pour configurer des adresses IP sur différents équipements. L'objectif est de mettre en place une infrastructure réseau fonctionnelle avec des routeurs, des switches et des hôtes.

Fichiers inclus :  configuration_ip_adress.pkt → Fichier Packet Tracer contenant la topologie réseau
